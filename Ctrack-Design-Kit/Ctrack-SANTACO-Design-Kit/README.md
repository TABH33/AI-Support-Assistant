# Ctrack / SANTACO design kit

Portable design assets extracted from the local SANTACO Mobility Command dashboard and aligned to the supplied Ctrack Brand Guidelines V4.

## Contents

- `colors.json` — machine-readable colour roles and usage guidance.
- `tokens.css` — ready-to-import CSS custom properties.
- `AI_USAGE_PROMPT.md` — a reusable prompt for applying the kit with an AI coding tool.
- `logos/ctrack-logo.png` — the supplied Ctrack logo used in the dashboard.
- `icons/*.svg` — scalable interface icons using `currentColor` where practical.

## Core visual rules

- Use Dark Blue and Teal for roughly 60–70% of a layout.
- Use Purple, Pink, Yellow and Orange sparingly for charts, statuses and source differentiation.
- Do not use extended colours for long-form body text.
- Prefer Red Hat Display for headings and Poppins for body copy, with system fallbacks.
- Preserve clear data provenance: Ctrack live = teal, Bolt live = purple, CAN mock = orange, combined/modelled = dark blue.

The Ctrack logo remains subject to Ctrack brand and trademark permissions. Do not redraw, distort, recolour or add effects to it.
